# Classical ABAP Exercises

Practical exercises and learning projects focused on Classical SAP ABAP development, covering beginner to advanced topics.

> **Note:** This repository contains personal learning exercises based on SAP official training materials, as well as examples and adaptations developed while following external learning resources, including Udemy and YouTube courses. The repository is intended for educational and portfolio documentation purposes and does not represent professional SAP project experience.
